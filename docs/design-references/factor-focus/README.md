# KanzQuant Factor Focus Micro Reference Pack

Canonical implementation references for the KanzQuant Factor Focus page.

Recommended repo destination:

`docs/design-references/factor-focus/`

Codex should inspect `00-full-factor-focus.png` first, then use the matching micro-reference for each component. The images define composition, density, spacing, hierarchy, chart treatment, and containment. They do not authorize copying generated values as real data.

The Factor Focus page is an analytical drill-down for one factor. It should explain the current factor state, how unusual it is, what drove the recent move, analogous historical episodes, and related factors without turning into a text-heavy report.
