# Evidence Library Visual Spec

## Purpose
A browse-first, read-only library of completed quantitative studies.

## Table
- Dense professional table.
- Sticky header.
- Internal vertical scrolling.
- Clear active sort column.
- Tabular numerals.
- Stronger evidence first by default when supported by a documented metric.

## Recommended columns
Study, Theme, Universe, Horizon, Reliability/Evidence, Significance, Sample (n), Effect, Hit Rate, Updated, Open.

## Statistical language
- `Statistically significant at the 5% significance level` or `at 95% confidence`.
- The *effect/difference* is significant, not the condition itself.
- Show `Insufficient evidence` when sample size/power is too weak.
- Prefer adjusted p-value when multiple-testing correction exists.

## Interaction
No public Run Test / Build Hypothesis action.
Open a study into the dedicated Study Focus page.
