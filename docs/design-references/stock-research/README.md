# KanzQuant Stock Research Micro Reference Pack

Use these crops as exact visual references when implementing the KanzQuant stock research page.

Recommended implementation order:
1. shell/header/sidebar
2. stock instrument header + section tabs
3. main chart + toolbar + indicator chips
4. quant snapshot + key information
5. historical evidence + significance summary
6. fundamentals
7. relative performance + correlation
8. macro context + news/catalysts

Important:
- Match composition, spacing, density, hierarchy, border treatment, typography scale, and containment.
- Use real KanzQuant data; do not copy mock values.
- Keep metadata inside its relevant panel.
- Preserve the text-only KanzQuant wordmark in the real product.
- Use SVG icons from the app icon system rather than rasterizing these images.
- Historical evidence should expose statistical significance, sample size, effect, confidence interval, and p-value when the methodology supports those values.
