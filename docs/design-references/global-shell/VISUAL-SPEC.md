# Global Shell Visual Spec

## Shell
- Compact top bar.
- Compact left navigation rail.
- Near-black page background with subtly differentiated analytical surfaces.
- No centered marketing-style max-width layout.

## Navigation
- Consistent thin line icons, approximately 18–20px.
- Selected item: bright blue icon/label with deep-blue background.
- Inactive: muted blue-gray.
- Avoid large labels and decorative chevrons.

## Controls
- Compact heights.
- One coherent control language for buttons, tabs, chips, dropdowns and icon buttons.
- Avoid multiple redundant control rows.

## Containment
Only page title/subtitle and global shell normally sit directly on the page background.
Panel-specific content belongs inside the panel header/body.

## Icon implementation
The icon sheet is a visual reference only. Implement icons as SVGs using one consistent library such as Lucide.
