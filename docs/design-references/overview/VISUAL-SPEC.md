# Overview Visual Spec

## Canonical hierarchy
- Left/main: dominant Market Overview chart.
- Right: Historical Analogues.
- Middle: six compact factor cards: Growth, Inflation, Rates, Liquidity, Credit, Volatility.
- Bottom: Rolling Volatility, Rolling Sharpe, Return Distribution, Correlation Matrix.

## Rules
- The main market chart must remain the strongest object on the page.
- Historical analogues are secondary and table-like, not giant cards.
- Factor cards are compact and equal in visual weight; they must not overpower the market chart.
- Factor cards should contain current level, z-score/state, percentile bar, and sparkline inside the card.
- Panel-specific dates, controls, legends, and metadata stay inside the relevant panel header.
- Use semantic color: blue for interaction/primary series; green positive; red negative; amber/purple/teal only where contextually useful.
- No fake BUY/SELL recommendations.
- Lower analytics should be compact and coordinated, visible on desktop without excessive whitespace.
