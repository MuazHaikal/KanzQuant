# Visual Spec — Data Catalogue

## Core principles
- Dense professional data workstation, not an admin/database console.
- Human-readable series name is primary.
- Technical identifiers are secondary.
- Show frequency, coverage, observation count, freshness, and source clearly.
- Panel-specific metadata stays inside the panel.
- Use internal scrolling for long series lists.
- Keep the selected-series detail rail visible on desktop.
- Raw schema/DB metadata belongs under collapsed technical details.
- Missing/insufficient data is explicit; never show NaN.
- Do not fabricate freshness or coverage.
