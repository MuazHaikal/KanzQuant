# KanzQuant Data Catalogue Micro Reference Pack

Extract this folder to:

`docs/design-references/data-catalogue/`

Use `00-full-data-catalogue.png` for overall composition and the numbered PNGs for component-level implementation reference.

The Data Catalogue should prioritize human-readable series names, frequency, coverage, observation count, freshness, and source. Raw provider IDs, storage/schema details, and other implementation metadata should remain secondary or collapsed.

The series table should scroll internally when needed, with its header remaining visible. Avoid making the whole page vertically scroll just to browse many series.
