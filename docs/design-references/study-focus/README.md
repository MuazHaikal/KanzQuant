# KanzQuant Study Focus Micro Reference Pack

Canonical micro references for the read-only Study Focus / Evidence result experience.

## Codex destination

Extract this pack into:

`docs/design-references/study-focus/`

Codex should inspect `00-full-study-focus.png` first, then use the numbered micro references for component-level implementation.

## Product rules

- This is a read-only research result experience. Public users do not run studies here.
- Show a short statistical conclusion first.
- Always surface sample size, effect size, confidence interval, p-value/adjusted p-value when available.
- Reliability is a ranking/display concept and must not replace statistical significance.
- Keep methodology/settings visible but secondary.
- Historical cases belong in a contained table with internal scrolling when content exceeds the card height.
- Preserve the canonical dark KanzQuant shell and compact analytical density.
