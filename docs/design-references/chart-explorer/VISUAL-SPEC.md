# Visual Spec — Chart Explorer

## Core rules
- Main chart is visually dominant.
- Instrument identity, price, change, OHLCV, range controls, interval selector, and indicator controls stay inside the main chart panel.
- Default chart indicators: SMA 20, SMA 50, Bollinger Bands (20,2), and Volume.
- Volume is integrated at the bottom of the price chart.
- Right rail is secondary and compact.
- Bottom analytics form a coordinated row.
- No fake BUY/SELL recommendations or fabricated forecasts.
- Use existing KanzQuant real data, historical analogues, and analytical modules.
- Keep metadata contained within its relevant surface.
- Avoid nested cards and excessive prose.
