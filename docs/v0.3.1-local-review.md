# KanzQuant v0.3.1 local review

Local-only interaction release. No push, deployment, ingestion, database migrations or quantitative-engine changes.

## Guided research

Explore is the default; Build retains the advanced builder. The explicit relationship map in `src/lib/guided-research.ts` produces research connections, not causal claims. Observed unusual moves take priority over factor levels. The existing classifications and ranks are reused.

Threshold policy: unusual/extreme direction maps to P10/P90; less unusual conditions map to P20/P80. Presets use fixed P10/P90 definitions. Market outcomes default to 6 months; 3 and 12 months are optional. No significance, threshold or horizon optimization. Automatic statistical method, seed, resampling, spacing, baselines, evidence rules and family FDR are unchanged. Changing the target of a prefilled question preserves its original condition.

## Chart Explorer

The central catalogue describes the existing three markets, six factors and persisted economic indicators. Human names precede identifiers. CPI/core CPI/PCE retain their original price-index units; no inflation transformation is invented for charts.

Selected series load bounded windows plus a buffer. Markets reuse existing candle aggregation. Monthly indicators retain their native observations, aligned using the engine's existing simplified monthly/quarterly release lags. Historical readouts use the latest available point at or before the selected date. No daily macro observations or pre-model market states are fabricated. Factor/state history starts 2006-11-30. S&P 500 has no misleading volume lane.

Chart, Compare, Context and Events share a calendar domain. Separate units are the default. Positive starting values can be normalized to 100; zero/negative starting values are visibly excluded. State changes and existing analogue dates supply event markers. Keyboard arrows pan, +/- zoom, Enter inspects, and Home resets. Date input can move the window to older history. Core selections/range/interval/mode/date are shareable in the URL. Manual pan/zoom bounds are session-local.

Saved views use browser-local storage, scoped to the local origin. They retain selections, stacked layout/mode, range, interval, comparison mode and inspected date, not data. Open, rename and delete are available. First-use help is optional, four steps, immediately dismissible, persisted and reopenable. The Visual Guide reuses existing visual components and explicitly labels illustrative examples.
